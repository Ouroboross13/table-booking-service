# Table Booking Service (Сервис бронирования столиков)

## Описание проекта
Спецификация бэкенд-сервиса, автоматизирующего процесс резервирования столиков в ресторане через клиентское мобильное приложение и веб-виджет.

## Границы проекта (Scope)
* **В скоупе (In Scope):**
  * Поиск доступных слотов по дате, времени и числу гостей.
  * Создание и отмена бронирования клиентом.
  * Валидация пересечений слотов (защита от овербукинга).
  * Управление жизненным циклом заявки.
* **Вне скоупа (Out of Scope):**
  * Онлайн-оплата депозита (запланировано на v2).
  * Интеграция с физическими кассовыми системами (iiko/r_keeper).

## Стек и стандарты артефактов
* **Спецификация API:** OpenAPI 3.0 (YAML).
* **Моделирование:** Mermaid.js (Sequence, State).
* **База данных:** PostgreSQL DDL.
