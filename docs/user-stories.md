# Пользовательские требования

### US-01: Создание бронирования столика
**Как** гость ресторана,  
**Я хочу** забронировать столик на определенную дату, время и количество персон,  
**Чтобы** гарантированно получить место без ожидания в живой очереди.

#### Критерии приемки (Acceptance Criteria):
* **AC 1 (Успешное создание):**
  * *Given:* пользователь выбрал стол #4 на 20:00 15 ноября, и этот слот свободен.
  * *When:* отправлен запрос на бронирование с валидным номером телефона (+79991112233).
  * *Then:* система сохраняет бронь в статусе `CONFIRMED`, возвращает уникальный `booking_id` и резервирует стол на 2 часа.
* **AC 2 (Конфликт слотов):**
  * *Given:* выбранный стол уже забронирован на указанное время другим клиентом.
  * *When:* отправлен запрос на бронирование.
  * *Then:* система отклоняет запрос с HTTP 409 Conflict и текстом ошибки `Table is already booked for this time`.
